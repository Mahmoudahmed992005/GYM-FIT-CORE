# FitCore Gym — Gym Landing Page

A single-page gym landing site built with vanilla **HTML5**, **CSS3**, and **Bootstrap 5**.

🔗 **Live Demo:** https://mahmoudahmed992005.github.io/GYM-FIT-CORE/

## ✨ Features

- 🏋️ Hero section
- 🌟 Feature highlights
- 🗣️ Member testimonials
- 📊 Live statistics
- 📝 Registration form

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3, Bootstrap 5 |

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Mahmoudahmed992005/GYM-FIT-CORE.git

# Navigate into the project
cd GYM-FIT-CORE
```

### Run

No build step required — just open `index.html` directly in your browser, or serve it with a live server:

```bash
# Using VS Code Live Server extension, or:
npx serve .
```
